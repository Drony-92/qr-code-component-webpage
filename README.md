# QR Code Component Webpage

## About the Project

This project is a simple and responsive QR Code Component created using HTML and CSS. It displays a QR code inside a clean and attractive layout.

## Screenshots

![A screenshot image of the QR Code Component webpage.](images/qr-code-wepbage-screenshot.png)

## Technologies Used

**HTML5:** Used to create the structure of the component.

**CSS3:** Used to style the component and improve its appearance.

**Mobile Responsive Design:** Ensures the component looks good on different screen sizes, including mobile phones, tablets, and desktops.

## Features

- Clean and simple design.
- Proper alignment using Flexbox.
- Mobile-friendly and responsive layout.
- Easy to understand and user-friendly interface.
